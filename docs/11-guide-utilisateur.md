# 11 · Guide utilisateur

*À destination des agents chargés du comptage lors d'une évacuation.*

## Accéder à l'application

Ouvrez l'adresse communiquée par le service informatique (ex. `http://comptage.entreprise.local`) dans Edge ou Chrome, depuis un PC, une tablette ou un smartphone du réseau de l'entreprise.

**Aucun mot de passe à saisir** : vous êtes reconnu automatiquement grâce à votre session Windows. Votre identifiant s'affiche en haut à droite. Toutes vos actions sont enregistrées à votre nom.

## Pendant un incident

### 1. Créer ou ouvrir l'incident
- Écran **Incidents** → **+ Nouvel incident** : choisissez le **type** (Incendie, Fuite chimique, Exercice, Autre), saisissez un **titre** (ex. « Incendie bâtiment B ») et éventuellement le **point de rassemblement**.
- Si un collègue a déjà créé l'incident, **cliquez simplement dessus** dans la liste « En cours ». Plusieurs agents peuvent compter sur le même incident en même temps : les listes se mettent à jour toutes les 5 secondes.

### 2. Compter les personnes internes
1. Dans le champ de recherche, tapez **au moins 4 lettres** du nom **ou** du prénom (ex. `dupo`).
   Astuce : tapez le début du nom **et** du prénom pour cibler (ex. `dupo jea`).
2. Les suggestions apparaissent sous le champ, avec le service de chaque personne pour distinguer les homonymes.
3. **Cliquez** sur la personne, ou utilisez les flèches ↑ ↓ puis Entrée.
4. Une fenêtre demande confirmation : cliquez sur **Ajouter**.
5. La personne apparaît dans la liste **Internes**, et le champ se vide pour la personne suivante.

Une personne déjà comptée apparaît **grisée « déjà comptée »** dans les suggestions et ne peut pas être ajoutée deux fois.

Seuls les lettres (avec ou sans accent), l'espace, l'apostrophe et le trait d'union sont acceptés. Un autre caractère (chiffre, `*`, etc.) affiche « Caractère non autorisé ».

### 3. Compter les visiteurs et les personnes hors annuaire
Prestataires, intérimaires, livreurs, ou toute personne introuvable dans la recherche :
1. **+ Ajouter un visiteur**
2. Saisissez le **nom complet** (lettres, accents, espace, apostrophe, trait d'union) et éventuellement la **société** (texte libre), puis **Continuer**
3. Confirmez avec **Ajouter**

Si la recherche affiche « Annuaire indisponible », utilisez aussi ce bouton pour les internes.

### 4. Lire les totaux
En haut de l'écran : **Internes**, **Visiteurs** et **Total présents**. Chaque liste est triée par ordre alphabétique et affiche aussi son total.

### 5. Corriger une erreur
- **Retirer une personne** ajoutée par erreur : bouton **Supprimer** sur sa ligne, puis confirmez.
- **Annuler un retrait** : en bas de page, ouvrez **Personnes retirées**, puis **Réintégrer**.

### 6. Imprimer ou exporter
- **🖨 Imprimer** : imprime les deux listes avec les totaux, la date et l'heure. Utile à remettre aux secours.
- **⤓ Export CSV** : fichier ouvrable dans Excel.

### 7. Terminer
- **✓ Clôturer** quand le comptage est terminé : les listes passent en lecture seule. **Rouvrir** permet de les modifier à nouveau.
- **Journal** : historique de toutes les actions (qui, quoi, quand).

## Supprimer un incident

**Supprimer l'incident** (après confirmation) le place dans la **Corbeille**. Rien n'est perdu immédiatement :
- menu **Corbeille** → **↺ Restaurer** remet l'incident intact, pendant **24 heures** ;
- passé ce délai, il est effacé définitivement et automatiquement.

Il n'existe **aucun bouton pour tout effacer**.

## En cas de problème

| Problème | Que faire |
|---|---|
| Une fenêtre demande un identifiant et un mot de passe | Saisissez vos identifiants Windows habituels, puis prévenez le service informatique |
| « Annuaire indisponible » | Ajoutez les personnes avec **+ Ajouter un visiteur** |
| « Serveur injoignable » | Vérifiez le réseau (Wi-Fi). Si le problème dure, comptez sur papier à partir de la dernière impression |
| Une personne n'apparaît pas dans la recherche | Essayez avec le prénom, ou l'autre partie d'un nom composé ; sinon, ajoutez-la comme visiteur |
